# Homebrew tap

Homebrew formulas for [mcp-mesh](https://github.com/AldrinSalazar/mcp-mesh).

```sh
brew install aldrinsalazar/tap/mcp-mesh-node
```

| Formula | What it installs |
| --- | --- |
| `mcp-mesh-node` | The node: shares a machine's MCP servers with an mcp-mesh hub. macOS and Linux, Intel and ARM 64-bit. |

Upgrade with `brew upgrade mcp-mesh-node`, then restart a running node:
`mcp-mesh-node stop && mcp-mesh-node start`.

The formulas are generated by mcp-mesh's release workflow; change them there,
not here.
